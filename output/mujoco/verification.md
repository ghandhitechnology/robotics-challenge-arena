# MuJoCo 검증 기록

MuJoCo 3.12.0에서 확인했습니다. 치수 근거와 기존 Blender/USD 검증은 상위 폴더의 `verification.md`에 있습니다.

| 검사 | 결과 |
| --- | --- |
| Python 물리·환경·보정 테스트 | 21개 통과 |
| 시니어·사진·울타리 사진 MJCF | 세 파일 모두 네이티브 모델로 컴파일 |
| 테이프 | 10개 flex, 1,323개 절점, 두께 0.15 mm |
| 형상·질량·접착 설정·구멍·초기 안정성 | [32개 검사 통과](validation.json) |
| 바퀴의 테이프 통과 | [실행 결과](wheel_crossing.json), 수치 경고 없음 |
| 정지 상태 유지 | 로봇 없는 전체 경기장 0.3초, 접착 손상 0, 최대 미끄럼 7.10 µm |
| 박리 메시 비교 | 5 mm에서 2.5 mm로 줄이면 평균 박리 힘 약 7.9%, 당김 일 약 3.2% 차이 |
| 상태 복원 | 난수·명령 지연·접착 이력까지 복원, 다음 관측·보상 일치 |
| Colab | [A100 런타임의 네이티브 실행과 NVIDIA 렌더링 기록](../../docs/colab_runtime.md) |

초기 마찰·탄성·접착 값은 실측 전 값입니다. 실제 키트와의 일치는 [보정 절차](../../docs/mujoco_calibration.md)로 확인해야 합니다. 네이티브 물리는 CPU에서 실행합니다. 현재 확인한 MuJoCo 3.12의 GPU Warp 모델은 접착 필드를 보존하지 않습니다.

테이프는 한 겹으로 맞댄 배치입니다. 두 겹 접합부는 안정성 검사 실패로 빌드에서 거부합니다. PVC 파단과 종이 박리는 구현하지 않았으며, 셸 변형 한계를 넘으면 예제 학습 환경이 에피소드를 중단합니다. 자세한 수치와 모델 범위는 [물리 근거 문서](../../docs/mujoco_physics_sources.md)에 있습니다.
