# 실물 측정과 MuJoCo 보정

기본 재료값은 경기장 실측값이 아니다. 경기장과 같은 종이, 도장된 목재, 테이프, 바퀴로 측정한 뒤 아래 도구로 프로필을 만든다. 단위는 m, kg, N, s, Pa이며 각도만 도 단위다. `null`인 측정은 건너뛴다. 반복 측정은 숫자 대신 배열로 입력할 수 있다.

```sh
.venv/bin/python scripts/calibrate_mujoco.py --write-template measurements/kit.json
# kit.json의 null을 측정값으로 채운다.
.venv/bin/python scripts/calibrate_mujoco.py \
  --input measurements/kit.json --output measurements/profile.json
```

`profile.json`은 시뮬레이터의 `profile` 인수로 읽는 프로필 패치다. `profile.report.json`에는 계산 결과, 적용하지 않은 추정값, 미입력 항목이 남는다. 기존 보정값을 이어서 사용할 때는 `--base-profile measurements/previous.json`을 추가한다. 기존 프로필의 항목도 새 출력에 보존된다. 빈 양식으로 실행하면 빈 패치와 미입력 목록을 만든다.

```python
from arena_mujoco import ArenaSimulation

sim = ArenaSimulation(profile="measurements/profile.json", randomize=False)
```

## 바닥·테이프·벽 마찰

종이 위 목재(`wood_paper`), 테이프 윗면 위 목재(`wood_vinyl`), 종이 위 고무 바퀴(`rubber_paper`), 테이프 위 고무 바퀴(`rubber_vinyl`)를 각각 측정한다. `vinyl`은 마른 윗면 접촉을 뜻한다. 테이프 접착면은 별도 박리시험으로 다룬다. 바퀴가 다른 재질이면 `robot.py`의 충돌체 재질부터 바꾼다.

- 정지 마찰: 경사면 각도를 천천히 올리고 **미끄러지기 시작하는 각도**를 `static_incline_deg`에 기록한다. 계산은 `μs = tan(θ)`다. 원통이나 바퀴는 회전을 고정한다. 전도나 구름이 먼저 발생한 시험은 사용하지 않는다.
- 운동 마찰: 수평으로 일정한 저속으로 끌 때의 힘을 `kinetic_pull.force_n`에 기록한다. 수평면 위 물체는 `mass_kg`, 별도 가압 장치를 쓰면 `normal_force_n`을 입력한다. 계산은 `μk = F/N`, 수평면에서는 `N = mg`다. 당기는 줄의 수직 성분을 피한다.
- 미끄럼 정지거리: `sliding_coast`에 `initial_speed_m_s`와 `distance_m`을 넣으면 `μk = v²/(2gd)`를 구한다. 수평면에서 회전 없이 미끄러지는 시험편에만 쓴다. 구르는 바퀴의 정지거리를 이 식에 넣지 않는다.

두 운동 마찰 시험을 함께 입력하면 각 방법의 추정치를 평균한다. 보고서의 개별 추정치가 크게 다르면 속도, 줄 각도, 표면 상태를 다시 확인한다. 측정된 운동 마찰이 정지 마찰보다 크면 변환을 중단한다. 한쪽만 측정해 기존 값과 순서가 뒤집혀도 다른 쪽 측정이 필요하다.

`walls`의 동·서·남·북은 서로 다른 시험편과 표면 상태로 측정한다. 실제 벽면 재료를 수평 시험 장치에 고정하거나, 벽에 누르는 수직항력을 재서 마찰력을 나눈다. 벽 보정은 현재 모델의 방향별 단일 배율에 맞춘다. 운동 마찰 측정이 있으면 그것을 우선 사용하며, 정지·비틀림·구름 마찰에도 같은 배율이 적용된다. 벽과 닿는 다른 재료의 마찰도 함께 검증한다.

프로필의 마찰 배열은 `[정지, 운동, 비틀림 길이, 구름 길이]`다. 앞의 둘은 무차원이고 뒤의 둘은 **m**다. 이 도구는 비틀림·구름 값을 측정된 미끄럼 계수로 대체하지 않는다. 실제 바퀴의 구름 저항과 제자리 회전 저항은 별도로 맞춘다.

## 질량·밀도·충돌

`densities`에서 물체의 질량과 실제 치수를 기록한다. `box`는 `size_m`, `cylinder`는 `diameter_m`·`height_m`, `perforated_plate`는 `size_m`·`holes`를 사용한다. 실험실 판의 기본 양식은 150 × 345 × 3 mm에서 지름 60 mm인 관통구멍 3개의 부피를 뺀다. 구멍은 서로 겹치지 않고 판 안에 있어야 한다. 실물 치수가 다르면 양식의 치수도 수정한다.

밀도는 `질량/재료 부피`다. 같은 재료의 여러 시험편은 총질량을 총부피로 나눈다. 목재 밀도는 현재 모든 목재 물체에 공유되므로, 종류별 결과가 크게 다르면 객체별 밀도와 관성으로 모델을 확장한다. 테이프는 이형지 없이 충분히 긴 길이를 재고, 실제 두께와 폭을 쓴다. `material: "vinyl"` 결과는 테이프 밀도에 적용된다.

낙하시험은 접촉점에서의 낙하 높이와 반발 높이를 `drops`에 기록한다. `sqrt(반발 높이/낙하 높이)`는 반발계수 추정값으로 보고서에만 저장한다. 여러 낙하 속도의 반발 높이·접촉 시간과 정하중 눌림량을 시뮬레이션에 맞춘 뒤 접촉 감쇠와 강성을 조정한다. 낙하 높이 하나로 `solref`를 자동 설정하지 않는다.

## 테이프 인장·말림·박리

인장시험은 작은 변형 구간에서 표점 길이(`gauge_length_m`), 폭, 두께, 늘어난 길이와 힘의 여러 점을 기록한다. 도구는 절편을 포함한 힘–변위 직선의 기울기 `k`를 구하고 `E = kL/(wt)`를 적용한다. 입력 구간은 변형률 2% 이하로 제한한다. 보고서의 `r_squared`와 잔차가 보이는 실측 곡선으로 선형 구간을 확인하고, 속도와 유지 시간도 기록한다. 파단 신율로 이 값을 대신하지 않는다. 결과는 접착층을 포함한 단일 셸의 유효 탄성률이다.

자유롭게 놓은 테이프의 말림 반지름을 `curl_radius_m`에 넣으면 기준 곡률 `1/R`을 적용한다. 현재 경기장 모델은 각 띠의 마지막 30 mm에 이 곡률을 적용한다. 띠 전체가 말리는 실험을 맞추려면 기준 형상도 확장해야 한다. 반대 방향은 `curl_sign: -1`을 쓴다. 붙였다 뗀 뒤의 영구변형과 새 테이프의 초기 말림을 구분해 기록하고, 시뮬레이션에서 방향을 확인한다.

박리시험은 실제 지도 종이와 테이프 겹침면을 각각 사용한다. 부착 압력, 대기 시간, 당기는 속도를 일정하게 두고 90°와 180°에서 정상 박리 구간의 힘을 잰다. `peel` 항목의 `force_n`, `width_m`, `angle_deg`, `speed_m_s`, `support`에 기록한다.

- 폭당 저항은 `F/w`이며 단위는 N/m다.
- 늘어나지 않는 배면을 가정한 에너지 추정치는 `(F/w)(1 − cos θ)`이며 단위는 J/m²다. 같은 힘이면 180° 추정치는 90°의 두 배다.
- 이 두 값은 보고서에만 저장한다. 박리 힘만으로 최대 접착 응력(`peak_traction_pa`)을 정하거나 파괴에너지(`fracture_energy_j_m2`)를 자동 갱신하지 않는다. 인장 분리, 전단, 속도별 박리 곡선까지 함께 맞춘다.

## 실제 로봇과 보정 확인

현재 로봇은 1 kg 기준 모델이다. 실제 로봇의 총질량·무게중심·관성, 차체와 범퍼 형상, 바퀴 반지름·간격·접지 폭, 캐스터, 감속비, 모터 토크–속도 곡선, 제어 지연을 측정해 `arena_mujoco/robot.py`와 제어 설정을 교체한다. JSON의 `robot`에서는 휠 출력축 기준 정지 토크 `max_motor_torque_nm`(N·m), 명령 각속도 상한 `max_wheel_speed_rad_s`(rad/s), 무부하 각속도 `motor_no_load_speed_rad_s`(rad/s), 속도 제어 이득 `velocity_gain`(N·m/(rad/s))을 갱신할 수 있다. 무부하 속도는 명령 상한 이상이어야 한다. 이득은 제어기 설정이며 재료 측정값이 아니다. rpm은 `rpm × 2π/60`으로 변환한다.

먼저 `randomize=False`로 종이·테이프 직진, 회전, 목재 밀기, 테이프 가장자리 통과, 박리를 실물과 비교한다. 같은 실험을 시간 간격과 테이프 격자 간격을 줄여 반복하고 결과가 수렴하는지 확인한다. 이후 반복 실험의 산포에 맞춰 무작위화 범위를 정한다. 접착 분리는 모델에 포함되지만 PVC 파단과 종이 찢김은 별도 모델이 필요하다. 셸의 허용 변형 한계를 넘으면 환경은 `tape_material_limit`으로 에피소드를 중단한다.

재료식의 가정과 MuJoCo 접촉 단위는 [물리 근거 문서](mujoco_physics_sources.md)에 정리되어 있다.
